# ExamOS 2026 — Complete Startup Guide
# =====================================
# How to run the client browser / everything from zero

# ─────────────────────────────────────────────
# STEP 1: REQUIREMENTS
# ─────────────────────────────────────────────
# Install these before anything else:
#
# 1. Node.js 18+      → https://nodejs.org  (Download LTS)
# 2. XAMPP            → https://apachefriends.org  (for MySQL on Windows)
# 3. Anthropic API key → https://console.anthropic.com
#
# Check Node.js is installed:
#   node --version   (should say v18 or higher)
#   npm --version

# ─────────────────────────────────────────────
# STEP 2: EXTRACT & SET UP
# ─────────────────────────────────────────────

# 1. Extract the zip to a folder, e.g.:
#    C:\examos\        (Windows)
#    ~/examos/         (Mac/Linux)

# 2. Open XAMPP Control Panel
#    - Click START next to MySQL
#    - Click START next to Apache (optional)

# 3. Create the database:
#    - Open browser → go to: http://localhost/phpmyadmin
#    - Click "New" on the left sidebar
#    - Database name: examos_db
#    - Collation: utf8mb4_unicode_ci
#    - Click "Create"

# ─────────────────────────────────────────────
# STEP 3: CONFIGURE THE SERVER
# ─────────────────────────────────────────────

# Inside the examos folder, go into the server/ folder.
# Copy .env.example → .env
# Then open .env and fill in:

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=            # leave blank if XAMPP default, or your MySQL password
DB_NAME=examos_db

ANTHROPIC_API_KEY=sk-ant-api03-xxxx   # Your real key from console.anthropic.com

JWT_SECRET=any-random-long-string-here-change-this
CLIENT_URL=http://localhost:3000
PORT=5000

# ─────────────────────────────────────────────
# STEP 4: INSTALL DEPENDENCIES
# ─────────────────────────────────────────────

# Open a terminal / command prompt in the examos/ folder, then run:

npm run install:all

# This installs packages for server, client, and electron.
# It will take 2–5 minutes the first time.

# If npm run install:all fails, run them one by one:
#   cd server   && npm install
#   cd ../client && npm install
#   cd ../electron && npm install

# ─────────────────────────────────────────────
# STEP 5: START THE APP (Web Version)
# ─────────────────────────────────────────────

# From the root examos/ folder, run:

npm run dev

# This starts:
#   ● Server  → http://localhost:5000
#   ● Client  → http://localhost:3000  ← OPEN THIS IN YOUR BROWSER

# On first start the server will:
#   ✅ Connect to MySQL
#   ✅ Create all tables automatically
#   ✅ Create default admin account
#   ✅ Seed 10 subjects (Maths, English, Physics, etc.)

# ─────────────────────────────────────────────
# STEP 6: LOG IN
# ─────────────────────────────────────────────

# Open browser → http://localhost:3000
#
# Admin login:
#   Email:    admin@examos.ng
#   Password: Admin@2026!
#
# ⚠ CHANGE THIS PASSWORD immediately after first login!

# ─────────────────────────────────────────────
# STEP 7: START THE DESKTOP APP (Electron)
# ─────────────────────────────────────────────

# The desktop app runs as a secure exam browser with kiosk mode.
# You need the server + client running first (Step 5), then:

npm run dev:desktop

# This opens the Electron window.
# When a candidate starts an exam, it locks into fullscreen kiosk mode.
# Admin can exit kiosk mode with the token: EXAMOSADMIN2026

# ─────────────────────────────────────────────
# STEP 8: USING THE PLATFORM
# ─────────────────────────────────────────────

# === ADMIN WORKFLOW ===
# 1. Go to Subjects → Add your subjects
# 2. Go to Question Bank → New Question (manual)
#    OR → Import Questions (upload CSV/JSON past questions)
# 3. Go to Exams → Create Exam → Pick questions → Set duration
# 4. Register candidates (Candidates page)
# 5. Launch the exam
# 6. Monitor live via Live Monitor tab
# 7. View results via Analytics

# === CANDIDATE WORKFLOW ===
# 1. Admin registers candidate with email + password
# 2. Candidate logs in at http://localhost:3000
# 3. They see assigned exams on their dashboard
# 4. Click "Start Exam" → opens secure exam browser
# 5. AI proctoring starts automatically (face cam, gaze, tab monitoring)
# 6. Submit → see results immediately

# ─────────────────────────────────────────────
# IMPORTING PAST QUESTIONS (WAEC/JAMB/NECO/NABTEB)
# ─────────────────────────────────────────────

# WAEC, JAMB, NECO, NABTEB do NOT have public APIs.
# The correct legal process:
#
# 1. Download the CSV template from the Import page (or from /api/import/template)
# 2. Fill in past questions from official question papers
# 3. Upload the CSV → preview → import
#
# CSV columns:
#   question_text  - The question
#   option_a       - Option A text
#   option_b       - Option B text
#   option_c       - Option C text
#   option_d       - Option D text
#   correct_answer - A, B, C, or D (or full text)
#   explanation    - Why that answer is correct
#   difficulty     - easy / medium / hard
#   marks          - Number (e.g. 1)
#   tags           - Separate with semicolons: WAEC;2023;Algebra
#   year           - e.g. 2023
#   subject_code   - MTH, ENG, PHY, CHM, BIO, etc.

# ─────────────────────────────────────────────
# AI PROCTORING SETUP
# ─────────────────────────────────────────────

# AI proctoring uses your Anthropic API key (set in .env).
# It analyzes:
#   - Face detection events
#   - Gaze/eye tracking events
#   - Tab switching attempts
#   - Audio spikes
#   - Full session behavioral patterns
#
# The webcam feed itself is processed in the browser (face-api.js).
# Claude AI analyzes the event data (not the video) for risk scoring.
#
# Get your API key at: https://console.anthropic.com
# Add it to server/.env as ANTHROPIC_API_KEY=sk-ant-...

# ─────────────────────────────────────────────
# COMMON ERRORS & FIXES
# ─────────────────────────────────────────────

# ERROR: "Cannot connect to database"
# FIX:   Make sure XAMPP MySQL is running. Check DB_PASSWORD in .env.

# ERROR: "Port 5000 already in use"
# FIX:   Change PORT=5001 in .env. Update vite.config.js proxy target too.

# ERROR: "Port 3000 already in use"
# FIX:   Change port in client/vite.config.js → server: { port: 3001 }

# ERROR: "Module not found"
# FIX:   Run npm run install:all again from the root folder.

# ERROR: AI features not working
# FIX:   Check ANTHROPIC_API_KEY in server/.env is valid and has credits.

# ERROR: Camera not working in exam browser
# FIX:   Browser must have camera permission. Use Chrome or Edge.
#        On desktop (Electron), ensure camera access is granted to the app.

# ─────────────────────────────────────────────
# PRODUCTION DEPLOYMENT (WizHosting / cPanel)
# ─────────────────────────────────────────────

# 1. Build the React frontend:
#    cd client && npm run build
#    This creates client/dist/

# 2. In server/index.js, add before routes:
#    app.use(express.static(path.join(__dirname, '../client/dist')));
#    app.get('*', (req, res) => res.sendFile(path.join(__dirname, '../client/dist/index.html')));

# 3. On WizHosting:
#    - Create MySQL database in cPanel
#    - Upload server/ folder via File Manager or FTP
#    - Copy client/dist/ into server/public/
#    - Set Node.js app in cPanel: startup file = index.js
#    - Add environment variables in cPanel Node.js setup
#    - Click "Run NPM Install" then "Start App"

# 4. Update server/.env for production:
#    NODE_ENV=production
#    CLIENT_URL=https://yourdomain.com
#    DB_HOST=your-cpanel-db-host
